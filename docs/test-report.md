## 4. 缺陷与修复记录

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| `bwfm` 搜不到 Bullet Waiting for Me | 首字母字段把英文整词当一个拼音段，只取首字符 | 按空白分词，ASCII 词取首字母；重新导入后 PASS |
| 构建报 “uncached or runtime data during prerendering” | Next 16 动态页面未包在 Suspense 内 | `/songs/[id]` 改为 Suspense + 内部 async 组件 |
| 下载只有单页 | 早期实现按当前页导出 | 改为当前难度整谱拼接；随后按需求裁掉每页页脚并提升到 2 倍分辨率 |
| 重复导入外号报唯一约束 | `Alias` 缺少唯一索引与 upsert | 迁移增加 `(songId, alias)` 唯一约束，导入改为 upsert |
| 筛选点击即刷新，缺少确认 | 初版筛选直接改 URL | 改为暂存状态，点击「搜索」统一下发 |

## 6. 响应式布局

- 桌面 1440×900：结果两列、每页 40 张，筛选区与分页完整，无横向滚动。
- 移动布局 500×900：结果单列、每页 10 张，胶囊换行、滑杆与搜索按钮可用，封面占位 1:1，无横向滚动。
- 限制：Edge headless 最小窗口宽度约 496px，无法直接以 390px 视口复测；布局本身为流式（`w-full`、`flex-wrap`、`min-w` 240px），静态推断 390px 可用，但未取得实测证据。
- 移动端分页按钮与跳页输入高度提升到 40px，改善触控；桌面仍为 32px。
