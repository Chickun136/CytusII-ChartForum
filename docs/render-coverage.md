## 4. 缓存与首屏性能

缓存服务：`lib/chart-service.mjs`

- 缓存路径：`.cache/charts/<chartId>/<signature>/<page>.svg`
- 签名：文件 mtime + size + 渲染器版本；谱面更新后自动失效
- 同一页并发请求会合并为一次渲染
- API：`GET /api/charts/<chartId>/<page>`，返回 `image/svg+xml`

生产模式实测（`npm run build && npm start`，`ai001_001_2` 第 0 页）：

| 指标 | 数值 |
| --- | --- |
| 冷启动请求 | 30.6 ms |
| 命中缓存 | 5.8 ms |
| 响应大小 | 2072 B |
| ETag 304 | 正常 |
| 越界页码 | 404 |

结论：首屏请求远低于 1 s 目标。

进程内基准：

```powershell
npm run render:bench -- ai001_001_2 0
```

结果：冷渲染 10.65 ms，缓存命中平均 1.24 ms（最小 0.87 ms）。

## 5. 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CHART_DATA_DIR` | 工作区 `Cytus II谱面数据/Cytus II 全谱面 5.3` | 谱面 JSON 目录 |
